## Objective: 
Create a basic website collaboratively using Git for version control.
## Tasks
1. The Manager creates a GitHub repository for the project and
invites all team members as collaborators.
2. The Manager creates the initial README.md file and makes
the first commit to the repository.
3.Each Developer creates their own branch.
(e.g., feature/frontend, feature/backend)
4.Each Developer makes changes to README.md file (completely)'
5. Use pull requests to merge changes from individual
branches into the main branch.
6. Share the repository link.
7. Add the screenshots with Git workflow, pull request page to
the repository
